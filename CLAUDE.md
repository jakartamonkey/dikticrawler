# crmexport directory

This directory holds three unrelated Go modules, each in its own subdirectory — don't mix them up:
- `jiraimport/` (renamed from the old root `crmexport` module): imports an exported Jira CSV into a SQLite CRM database.
- `sekolah-crawler/`: crawls Indonesia's public school database (Kemendikdasmen). See its own CLAUDE.md.
- `pddikti-crawler/`: crawls Indonesia's higher-education institution database (PDDikti). See its own CLAUDE.md.
